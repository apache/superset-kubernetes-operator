# Adopters

This is a list of organizations that use the Apache Superset Kubernetes Operator.

Entries are self-reported by members of each organization. Inclusion in this list does not imply endorsement by the Apache Software Foundation or the Apache Superset project.

## Adding your organization

Open a pull request that adds a row to the table below. By submitting the pull request, you confirm that you are authorized to publicly identify your organization as an adopter. Maintainers only review the format of the entry.

Keep rows in alphabetical order by organization name. The description is optional.
