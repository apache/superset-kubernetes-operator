# In-repo SHA-256 pins for tool binaries downloaded by Makefile recipes
# (rumdl, golangci-lint, controller-gen, operator-sdk, opm) and by
# scripts/install-helm-unittest.sh. Those recipes and the installer verify every
# download against this file via scripts/verify-tool-checksum.sh and fail closed
# when an artifact is unpinned or does not match, so a compromised upstream
# release or a moved tag is detected instead of silently executed.
#
# Entry format (one per line): <sha256>  <version>/<asset-name>
#
# Regenerate after bumping RUMDL_VERSION, GOLANGCI_LINT_VERSION,
# CONTROLLER_TOOLS_VERSION, OPERATOR_SDK_VERSION, or OPM_VERSION in the
# Makefile, or HELM_UNITTEST_VERSION in scripts/install-helm-unittest.sh:
#
#   make sync-tool-checksums
#
# and commit the result. rumdl, golangci-lint, operator-sdk, and helm-unittest
# hashes are cross-checked against the upstream per-release checksum manifests;
# controller-gen and opm publish no manifest, so their binaries are hashed
# locally.
